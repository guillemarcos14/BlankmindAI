# App Store privacy reconciliation, version1.9

Public policy: https://blankmind.ai/privacy. This candidate adds measured-rest persistence, optional additional Health context, optional EU usage-bin access and aggregate experiment learning. Its privacy draft must replace the published policy before activating these new flows. The native account consent names OpenAI and ElevenLabs; refusal/withdrawal preserves basic blocking. Additional Health context and usage access have separate optional choices. Completed spoken text can contain personal context.

Match App Store Connect to the actual enabled release, including retained legacy services. The old1.7 checklist excludes health and user content and must not be reused. The1.8 checklist incorrectly treats user ID as contact information and its blanket Analytics purpose must not be applied to health data.

| Actual flow | Apple category | Purpose / linkage |

| Apple-provided email/private relay stored by Supabase Auth; support email when supplied | Contact Info: Email Address | App Functionality; linked to account |
| Authentication user ID, install ID, voice turn/quota identifiers | Identifiers: User ID / Device ID as appropriate to each identifier | App Functionality; product-event Analytics only for the event identifier; linked to account/install |

Exact selected apps/websites, original clinical documents, passwords, contacts, browsing/domain histories, IDFA and payment card details are not transmitted by these flows. Additional Health summaries and clinical-context entries are transmitted only under their explicit optional consent and remain Health data. Global learning shares only outcome aggregates per Watch metric and pre-sleep lead-time bucket after at least 20 other contributing consenting users; the personal records remain linked at rest. Generated ElevenLabs output is synthetic speech; this route does not upload a microphone recording or persist an audio recording. Do not mark Audio Data solely because text is played aloud. The app microphone is a separate upload through the authenticated backend to OpenAI transcription, and its transcript becomes user content. Review Audio Data against Apple collection definitions and actual provider retention. Apple keyboard dictation is distinct. Any future crash SDK needs its own declaration before activation.

Tracking remains No for the reviewed app flows; no third-party advertising SDK/IDFA is introduced. Do not claim anonymous/non-linked merely because an identifier is generated by the app: it persists and can connect to an authenticated account. No verified new App Store Connect privacy-label write is recorded in this task; review the existing ten declared types against the table and only change fields where their actual flow differs.
