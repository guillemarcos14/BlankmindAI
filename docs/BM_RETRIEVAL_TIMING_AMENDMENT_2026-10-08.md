# Timing instrumentation amendment

Discovered during final review, before publishing results: JSON callback first_text_ms resets when generate emits an empty draft before another attempt. Thus it measures the first draft of the final attempt, not necessarily the first text ever shown. Raw cumulative drafts reveal retries; their original timing cannot be reconstructed exactly. Existing real NDJSON handler measurements preserve the first nonempty frame without reset and are valid for that definition.

Keep the original160-case/364-turn corpus, all responses and failures. No runtime or corpus adjustments, no resampling to replace a failure. Add an explicitly labelled timing replay of all80 factual cases, same frozen fixtures and source, exclusively using the actual assistant-app-stream NDJSON handler. This is80 repeated pairs/160 additional turns, not80 fresh holdout cases. It measures input→first nonempty NDJSON draft and input→durable result, including source/classifier fallback and repairs. NDJSON draft reset frames cannot reset the timestamp. Report errors and every paid request separately, with the shared4USD cap. Do not transfer original quality verdicts to new outputs.

Use NDJSON timing replay as primary first-visible-text timing evidence. Original full-corpus JSON callback timings retain their true label (final-attempt draft), and original completion/error/cost results remain valid. Original20 NDJSON pairs remain a first-ever-text confirmation subset. Physical iPhone, deployed candidate, voice and network transport are not measured.

The80 eligible cases are correlated by ES/EN versions and authored profile choices, not an IID sample. The original manifest has22 multiphase conversations (not24 claimed in descriptive metadata),182 turns/variant,179 distinct input strings and no exact overlap with80 previous retrieval-corpus inputs. These metadata corrections do not alter questions, fixtures or gates.

The original protocol described 160 independent cases and a rule-of-three confidence bound. That claim is withdrawn: the corpus contains 80 correlated ES/EN scenario/profile families authored by the implementer, without IID sampling. No population confidence bound is justified. The original budget forecast also excluded much of the actual reviewer volume; the persisted 4 USD ceiling still applies to every request.

Its original checkpoint and failure are retained; that turn is never retried. The adapter was fixed and only still-unattempted turns were reviewed, reusing prior verdicts solely when the entire reviewer-input digest is identical. The full application runtime and response corpus remain unchanged.
