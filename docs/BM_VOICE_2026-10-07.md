# Blankmind voice by turns

## Scope and behavior

Independent feature branch `codex/bm-voice-2026-10-07`, based on the current Health onboarding release `9e4e61b`. No Jev dependency or changes to its branch. The explicit approval to implement this plan enables spoken replies in the app and supersedes the historical text-only decision for this app feature only. WhatsApp/SMS are unchanged.

Existing AAC recording/transcription is reused. A newly completed voice message plays its committed reply automatically while Chat is visible and active. Written messages, history reload, pending-message recovery and retries remain silent. Listen explicitly repeats the current final reply. Stop/cancel, mute, new recording, new message, leaving Chat, background, account change, audio interruption and route change stop playback. AI-generated voice is disclosed beside the controls; failure preserves the text and offers explicit Listen retry.

## Authority and privacy

`assistant-app-voice` is Netlify API2 streaming NDJSON carrying mono 24kHz little-endian signed PCM and an explicit end frame. It authenticates the existing Apple user and installation and reads the owned `completed` turn. It rejects client text and rechecks the reply after reservation. No planner, new conversation, native action or memory writes. One `gpt-4o-mini-tts` request using `marin` reads the entire committed visible reply, with a calm conversational instruction. No extra model-generated summary and no speech from provisional drafts.

Audio is transient, with no audio files/caches/URLs in storage or logs. The iOS engine buffers approximately two seconds with backpressure. Generation is bounded at 12MB PCM and 120s; invalid/truncated/error streams fail visibly. The server aborts the provider stream on cancellation. The client validates account ownership throughout streaming and isolates callbacks by generation.

Migrations031–033 contain service-only, content-free usage reservations. Deleting a turn clears its usage reference and preserves the live account budget; deleting the account removes its personal reservations. A separate hourly aggregate contains no personal identifiers and preserves the global cap across account deletion. Atomic global lock enforces 20 requests/hour/user, 100/day/user and 1000/day globally. Failed/cancelled generations consume a reservation, preventing retry cost amplification. Reusing a request UUID cannot regenerate speech. Explicit replay uses a fresh UUID. These are request/character bounds, not a monetary guarantee.

`BM_VOICE_ENABLED=true` enables the backend; default/off fails back to text. Rollback sets it false without deleting conversations or changing native blocking.
